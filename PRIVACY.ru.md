# Политика конфиденциальности More Boosty

**Русский** · [English](PRIVACY.md)

Обновлено: 20 ноября 2026 года.

More Boosty — независимое браузерное расширение, которое поддерживает
[WeslyG](https://github.com/WeslyG/more-boosty). Его единственная задача — показывать ссылки
на видео Boosty в разных качествах и на превью для материалов, которые вы вправе сохранять.
Расширение не связано с Boosty и не одобрено платформой.

## Какие данные используются

Расширение локально проверяет текущую страницу Boosty, чтобы найти видеоплееры, URL поста,
идентификаторы автора, поста или выбранного диалога. Рядом с поддерживаемым плеером появляется
пояснение об обработке данных и кнопка «Показать ссылки на видео».

Только после нажатия для конкретного поста или диалога расширение читает токен доступа Boosty,
если он есть в локальном хранилище сайта. Токен используется для HTTPS-запроса выбранного контента
к `https://api.boosty.to`. Пароль не запрашивается, сессии других сайтов не читаются.

Ответ API может содержать текст и медиа поста либо до 300 последних сообщений выбранного диалога.
Ответ обрабатывается в памяти для извлечения идентификаторов видео, ссылок на доступные качества
и превью. Текст, сообщения и остальные поля ответа в кэше не сохраняются.

## Кому передаются данные

Токен доступа и идентификаторы выбранного контента отправляются только API Boosty.
Разработчик расширения, рекламные и аналитические сервисы эти данные не получают.
У расширения нет собственного сервера для сбора данных.

При нажатии на ссылку видео или превью браузер подключается к HTTPS-медиасерверу, указанному Boosty.
Он получает запрос и обычные сетевые сведения, например IP-адрес. В ссылках могут присутствовать
параметры доступа, выданные Boosty. Расширение не добавляет к таким запросам токен сессии Boosty.
На стороне Boosty и медиапровайдеров действуют их собственные правила обработки данных.

## Хранение и управление

Токен, разрешения текущей вкладки, идентификаторы контента и видеоссылки находятся во временной памяти.
Кэшированные ссылки считаются устаревшими через пять минут и удаляются при следующей операции
с кэшем либо при остановке фонового процесса. Кэш содержит не более 50 записей контента.
Токены входят во временные ключи кэша для разделения сессий; расширение не записывает их на диск
и не выводит в логи.

Разрешение действует для выбранного контента в текущей вкладке и сбрасывается при полной
перезагрузке страницы или закрытии вкладки. Сохраняется не более 50 разрешений на вкладку.
Данные нового контента не запрашиваются до вашего нажатия. Закрытие всех вкладок Boosty
и отключение расширения останавливает обработку и очищает запущенные контексты.
Удаление расширения не завершает вашу сессию Boosty и не удаляет файлы, сохранённые браузером.

Расширение не использует cookies, историю браузера, Chrome Storage, аналитику, рекламу,
продажу данных или просмотр данных людьми. Существующим хранилищем сайта управляет Boosty;
загрузками и историей посещений управляет браузер.

## Ограниченное использование данных

Использование данных в More Boosty соответствует Chrome Web Store User Data Policy,
включая требования Limited Use. Данные используются только для описанной функции видеоссылок,
а не для рекламы, профилирования, решений о кредитоспособности или посторонних задач.

## Контакты и изменения

По вопросам конфиденциальности обращайтесь к разработчику через
[Issues проекта](https://github.com/WeslyG/more-boosty/issues).
Не публикуйте токены, подписанные ссылки на видео, приватные сообщения и другие чувствительные сведения.

При изменении обработки данных эта политика будет обновлена. Перед началом новой обработки
изменения также будут раскрыты в интерфейсе расширения.
