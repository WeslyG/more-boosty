# Публикация More Boosty в Chrome Web Store

**Русский** · [English](publishing.en.md) · [README](../README.md)

GitHub Release создаётся автоматически по тегу; отправка в Chrome Web Store выполняется отдельно.
Расширение поддерживает русский и английский языки. Материалы карточки подготовлены для обоих языков.

| Назначение | Русский | English |

| Карточка, краткое описание и обоснование разрешений | [listing.json](../store/ru/listing.json) | [listing.json](../store/en/listing.json) |
| Политика конфиденциальности | [PRIVACY.ru.md](../PRIVACY.ru.md) | [PRIVACY.md](../PRIVACY.md) |

| Локализация расширения | [messages.json](../source/_locales/ru/messages.json) | [messages.json](../source/_locales/en/messages.json) |

`source/_locales` входит в ZIP расширения. Файлы `store/*/listing.json` — подготовленные тексты
для полей кабинета магазина, а не файлы автоматического импорта.
Поле `screenshot` в них указывает на локальный файл.
Английский язык является основным (`default_locale: en`); добавьте русский перевод карточки в кабинете.

## Подготовка

1. Выполните `npm ci`, `npm test` и `npm run release` либо скачайте ZIP из проверенного GitHub Release.
   Для магазина нужен `release.zip` или `more-boosty-vX.Y.Z.zip`, не архив «Source code».
2. Проверьте обычный пост, несколько плееров, ленту, медиа и выбранный диалог.
   Для закрытого контента используйте собственный аккаунт с законным доступом.
3. Опубликуйте изменения в основной ветке, чтобы ссылки на политики из `listing.json` открывались без входа.
   Локальный файл сам по себе не является публичной privacy policy.
4. В кабинете разработчика укажите и подтвердите email, заполните сведения издателя,
   включите двухэтапную защиту Google-аккаунта и заполните сведения о распространении, которые запрашивает кабинет.

## Поля карточки

Загрузите архив, заполните название, описание, категорию и скриншоты.
Перенесите `short_description`, `description`, `single_purpose` и `host_permission_justification`
из соответствующего языка `listing.json` в одноимённые по смыслу поля кабинета.
Укажите URL политики конфиденциальности и поддержки.

В разделе remote code выберите **No, I am not using remote code**.
Весь исполняемый код находится внутри расширения; API возвращает данные JSON.

## Privacy practices

Не указывайте, что расширение не обрабатывает данные. Текущий код использует:

- **Authentication information** — токен текущей сессии Boosty.
- **Website content** — данные поста и видеоплеера.
- **Web history** — только URL/идентификаторы выбранного контента текущей страницы Boosty,
  без доступа к истории браузера.
- **Personal communications** — ответ API выбранного диалога может включать сообщения.

Сверьте эти категории с актуальными определениями и полями кабинета перед отправкой.
Раскрытия должны совпадать с кодом, карточкой, уведомлением под плеером и обеими privacy policies.
Данные не продаются и не используются для рекламы, профилирования или посторонних целей.

## Доступ для модератора и ограничения

В тестовых инструкциях укажите доступную модератору страницу и шаги:
открыть видео, прочитать пояснение, нажать кнопку и выбрать качество.
Не передавайте личный токен и не прикладывайте чужие приватные сообщения.

Google запрещает несанкционированное скачивание и обход ограничений доступа.
Доступ к просмотру не подтверждает право скачивать видео; пояснение в интерфейсе не заменяет
разрешение правообладателя. Не обещайте обход подписок или скачивание любых платных материалов.
Решение о публикации принимает модерация Google.

Проверка 20 ноября 2026 года: в Chrome 157.0.8103.79 на предоставленном публичном тестовом посте
появились шесть качеств от 1080p до 144p и превью; медиасервер вернул HTTP 200 на HEAD-запрос.
Видео целиком не скачивалось. Закрытые посты и диалоги требуют отдельной проверки с аккаунтом.
